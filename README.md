
# Twitter Clone

A simple **Twitter-style social network** built with **React**, **React-Bootstrap**, and **Session Storage**. This project allows users to post content, attach images, and view user profiles — all simulated on the frontend.

---

## Features

-  **Post tweets** with optional image attachment
-  **View all users' posts** sorted by date
-  **User profile view**, including cover and profile pictures
-  **Session Storage-based state management** 
-  Responsive UI styled using **React-Bootstrap**

---

#🧰 Technologies Used

- [React](https://reactjs.org/)
- [React-Bootstrap](https://react-bootstrap.github.io/)
- [Bootstrap 5](https://getbootstrap.com/)
- SessionStorage (for persisting users, posts, and profile data)
